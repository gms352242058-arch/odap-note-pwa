# 오답노트 웹(PWA) — 갤럭시탭 / S23용

Electron 앱(`../오답노트앱`)의 화면을 그대로 쓰고, 데이터는 Google Drive의 `전기기사오답노트앱` 폴더
(PC 앱과 같은 폴더)를 직접 읽고 씁니다. 서버 없이 정적 파일만으로 동작합니다.

## 파일
- `index.html`, `renderer.js`, `styles.css` — 화면 (PC 앱 코드 + 폰 레이아웃/이미지 지연 로딩)
- `web-api.js` — Electron의 main.js/preload.js 역할을 Drive REST로 대체 (로그인, 덱 읽기, 풀이 기록 병합·저장, 이미지, 오프라인 캐시)
- `sw.js`, `manifest.webmanifest`, `icons/` — 홈 화면 설치·오프라인 실행
- `katex/` — 수식 렌더링 (로컬 복사본)
- `demo/` — **로컬 테스트 전용 샘플(문제 이미지 포함). 호스팅에 올리면 안 됨**

## 로컬에서 보기
```
python -m http.server 8765 --directory .
```
`http://127.0.0.1:8765/?demo` — 로그인 없이 샘플 덱(2022-04-24)으로 화면 확인.

## Google 로그인 준비 (한 번만)
계정: gms352242058 (Drive 폴더가 있는 계정)
1. console.cloud.google.com → 프로젝트 `odap-note-pwa` 만들기 (**결제 계정은 연결하지 않기**)
2. API 및 서비스 → 라이브러리 → **Google Drive API** 사용
3. OAuth 동의 화면: 앱 이름 `오답노트`, 사용자 유형 **외부**, 지원 이메일/개발자 이메일 입력,
   범위에 `.../auth/drive` 추가, **테스트 사용자에 본인 계정(gms352242058) 추가**
4. 사용자 인증 정보 → OAuth 클라이언트 ID 만들기 → 유형 **웹 애플리케이션**
   - 승인된 JavaScript 원본: 호스팅 주소 (예: `https://<아이디>.github.io`), 로컬 테스트용 `http://127.0.0.1:8765`
5. 발급된 **클라이언트 ID**(…apps.googleusercontent.com)를 앱 첫 화면에 붙여넣고 로그인
   (클라이언트 보안 비밀은 필요 없음)

참고: 동의 화면이 "테스트" 상태면 약 7일마다 다시 로그인해야 할 수 있음. "프로덕션으로 게시"하면 풀리지만
`drive` 범위는 제한 범위라 "확인되지 않은 앱" 경고가 뜸(본인 계정만 쓰므로 계속 진행하면 됨).

## 동기화 방식
- 시작할 때 폴더 목록 → 바뀐 덱만 다시 받음(IndexedDB 캐시, 오프라인 가능).
- 풀이 기록(`app_data.json`, 약 3MB)은 변경 후 4초 모아서 올리고, 화면을 닫을 때도 올림.
- 올리기 전에 Drive의 최신 기록과 비교: 한쪽만 바뀐 카드는 바뀐 쪽을 따르고, 양쪽 다 바뀐 카드는 시도 기록을 합침.
- 카드 수정 시 `.bak` 백업을 (없을 때) 1회 만듦.

## 폰에서 다른 점
